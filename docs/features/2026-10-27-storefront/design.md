# Form & Field 商品选购应用

## 背景

为海外消费者制作可以向客户演示的 React 商品选购应用。核心路径为发现商品、搜索筛选、查看详情、选择颜色、加入购物车与调整购物车。

## 设计方案

- 英文界面、USD 标价，虚构品牌 Form & Field，精选家居、随行用品、数码和生活用品。
- 相比综合商城的高密度促销布局、单品品牌的长篇营销布局，采用精品选物商店布局，让商品图片和分类承担主要浏览工作。
- 白色 #ffffff、墨色 #222722、森林绿 #254d3e、浅绿 #edf2ec、边框灰 #e5e8e3、陶红 #b64f3c。图片可包含蓝、红、木材等商品本色，避免全站单色化。
- Manrope 用于品牌与标题，DM Sans 用于正文。左对齐、有节制的字重与留白；桌面四列，平板三列，手机两列商品。
- 首页为购物界面：公告条、品牌及搜索、分类导航、家居场景系列横幅、服务信息、分类筛选、商品网格、精选系列与页脚。
- 搜索即时匹配名称、分类和描述；分类、价格、库存、合集与收藏筛选组合生效；支持推荐、价格和评分排序；无结果时提供清除入口。
- 商品详情展示真实图片、评分、颜色、数量、材质和配送政策，使用无障碍弹窗。
- 购物车侧栏支持颜色区分、同款合并、数量上限、移除、免运费进度、正确金额计算。使用整数美分计算，localStorage 保存。
- 结算按钮展示明确标注的演示结算摘要，不收集银行卡，不产生真实订单。购买流程之外不引入登录、真实支付或后端系统。
- 搜索、收藏、购物车具有空状态；保存失败不阻断当前会话；存储数据损坏时恢复空状态。

## 架构与模式决策

React + TypeScript + Vite，Lucide 图标，Radix Dialog 处理弹窗焦点和键盘。
商品目录、纯领域函数、持久化状态 Hook、页面组件分别负责各自行为。
购物车具有多个明确状态转移，使用 reducer；仅提取货币、搜索、购物车计算等廉价可逆纯函数，不引入重型状态框架、继承或策略注册。

## 影响范围

空目录全新实现，不存在历史调用方或迁移要求。创建 src、public、构建配置和使用说明，不操作其他目录。

## 验收

- 1440px、768px、390px、375px 下无页面横向溢出，图片加载完整。
- 搜索、组合筛选、无结果恢复、收藏、商品颜色数量、加购合并、购物车调整和刷新恢复可演示。
- 弹窗支持关闭按钮、Escape、遮罩关闭和焦点恢复；减少动态效果系统偏好被尊重。
- 购物车和筛选核心分支通过单元测试，生产构建通过，使用浏览器实际验证核心路径。
