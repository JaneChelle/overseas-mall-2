# 验收记录

日期：2026-10-27

## 交付内容

Form & Field 海外消费者选购应用，英文界面、USD 价格、12 件示例商品，React + TypeScript + Vite。

## 实际验证

- `npm test`：11 项领域测试 + 4 项组件交互回归测试通过。
- `npm run test:e2e`：Google Chrome 中 7 项浏览器测试通过。
- `npm run build`：TypeScript 检查和 Vite 生产打包通过。
- 已覆盖 1440、768、390、375px，无页面横向溢出；全部图片成功解码。
- 浏览器实际覆盖：搜索、分类、组合筛选、价格排序、无结果恢复、收藏、损坏存储恢复、详情颜色与数量、同色合并、不同色分行、购物车增减、移除、刷新恢复、结算预览、Escape 关闭与焦点恢复。
- 人工复查桌面整页、手机整页、375px 商品详情及购物袋截图。
- 商品、头像、字体都由本项目提供，不依赖运行时的外部图片或字体服务。

## Review 与修复

外部代码审查发现三项，独立核对并按 RF-L1 事实纠错处理：

1. 详情加购的通知位于 Radix 焦点与点击隔离区域之外。加购后关闭详情，恢复页面交互；组件测试验证 body 点击恢复且 View bag 能打开购物袋，浏览器复测通过。
2. 卡片选色没有传给详情。扩展 `ProductCard.onOpen(color)`，显式传入 `ProductDialog.initialColor`；搜索所有消费者并同步，组件与浏览器测试通过。
3. 显式 smooth 滚动忽略减少动态效果偏好。抽取 `preferredScrollBehavior` 与 `scrollToTop` 纯粹的浏览器工具，统一覆盖分类、搜索、页眉、页脚和面包屑。两个交互回归测试通过。

Self-Review：

- SR-L1：搜索选色接口、旧滚动调用、外部图片字体地址和未完成标记，核对调用一致性。
- SR-L2：设计、说明、详情配送政策与演示结算边界一致；修正国际配送措辞。
- SR-L3：核查库存跨颜色共享、存储脏数据、数量零值与上限、空购物车运费、弹窗退出焦点和通知交互。
- 图片验收发现头像下载超时和部分商品图片不对应，替换为本地可用图片，四个视口图片解码测试通过。

## 规则执行清单

- ☑ 目标与范围：浏览、发现、详情与购物车为核心，不接入真实支付、登录或后端。
- ☑ 变更影响：颜色接口与滚动工具所有引用均经 `rg` 排查，TypeScript 编译及交互测试验证。
- ☑ 模式约束：购物车使用 reducer，计算与筛选使用纯函数；未引入继承、策略注册或额外状态框架。
- ☑ 自检与 Review：外部只读审查、SR 三层检查、发现问题立即修复并回归验证。
- ☑ 编码规范：美分、免运费阈值、存储 key、动画和通知时长集中命名；公共函数及边界逻辑有契约注释。
- N/A 历史兼容：空目录新项目，无历史调用链、迁移或旧行为需要保留。
- N/A Git 提交：当前目录不是 Git 仓库，未擅自初始化或提交。
- 工具降级：无可用 LSP 引用工具，使用 `rg` 引用搜索、TypeScript 与浏览器实测替代；未覆盖动态反射引用（本项目未使用）。

## 演示边界

商品、价格、评分、库存均为示例。颜色不会切换商品图片。支付和订单不产生真实交易；上线前需换成授权商品素材、连接商品库存 API 并完成支付与税费服务。
